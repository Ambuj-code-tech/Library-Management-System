# Library Management System

A console-based Library Management System built in C++ using Object-Oriented Programming (OOP), the Standard Template Library (STL), and File I/O.

## Features

- Add books
- Remove books
- Search books
- Register users
- Issue books
- Return books
- Save and load data using files

## Technologies Used

- C++
- Object-Oriented Programming
- STL
- File Handling
